# Reels Editing plugin

Edits raw phone videos into polished vertical Reels / Shorts / TikToks.

Skills:
- reels-edit: start here; routes the job and handles polish + quick captions
- embedded-captions: animated word-by-word caption styles (HyperFrames, by HeyGen)
- talking-head-recut: titles, lower-thirds, callouts, PiP over talking-head video (HyperFrames)
- hyperframes, hyperframes-core, hyperframes-animation, hyperframes-cli, media-use: HyperFrames engine skills the two above depend on
- clipify: cut long videos into short captioned clips (MIT, louisedesadeleer/clipify)
- ffmpeg: general video/audio processing (from OpenMontage)

Requirements: ffmpeg; Node.js for HyperFrames; Python + Whisper for automatic transcription.

Sources and licenses: heygen-com/hyperframes (Apache-2.0), louisedesadeleer/clipify (MIT), calesthio/OpenMontage (AGPL-3.0). Full texts in licenses/.
